## Confirmed issues and fixes

1. **Configured administrator password is stale relative to the stored account (high, operational recovery not run).** Read-only verification showed the `.env`-configured password does not match the existing active administrator's Argon2 hash. Bootstrap is create-only, so rerunning it or editing `.env` cannot repair an existing account. Added `reset-admin-password`; it targets only the configured existing active admin, requires typed identity confirmation, hidden double entry, and a minimum length. Recovery runs only when the operator explicitly executes the documented command.
2. **Model tests depended on local artifacts and shared worker state (medium, test isolation).** Copying canonical model folders also copied ignored local checkpoints, changing expected metadata from `MISSING_WEIGHTS` to `LOADING`; a shared handoff directory could also override catalog status. Tests now copy package files while excluding weights and isolate `MODEL_ROOT`/`HANDOFF_ROOT`.
3. **Windows preview manifest `PermissionError` (unconfirmed).** In an isolated API/worker run, 40 authenticated preview reads overlapped with synthetic frame publication without failures. Existing code uses six bounded replace attempts and logs a manifest-lock warning; it does not convert a locked manifest into a fresh frame. The previously observed intermittent production issue was not reproduced under this synthetic load, so no worker change was made.
