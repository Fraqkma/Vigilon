# Model package contract

Schema version 1 is implemented in `backend/app/ai_hub.py`. Only the built-in IDs `people_vehicle` and `fire_smoke` and their exact adapter IDs are accepted. `manifest.yaml` declares `module_id`, `package_version`, adapter, `task: detect`, minimum and actually tested runtime versions, package-relative weights and metadata paths, optional SHA-256, supported events, model card, and evaluation file. Metadata paths may not escape the package directory. Import paths, commands, and package installation instructions are not accepted. The starter templates have no tested runtime versions recorded; 8.4.0 is the pinned minimum adapter target, not a runtime-validation claim. The supported deployment lock pins exactly `ultralytics==8.4.0`.

`classes.json` maps checkpoint numeric class IDs to unique canonical labels; object values may use `{ "label": "..." }` to leave room for aliases. Runtime validation compares the full ID/name mapping to checkpoint names. Names are not inferred from class order. Inference YAML allows only `imgsz`, `conf`, `iou`, `classes`, `device` (`cpu`, `cuda`, `auto`), and `allow_cpu_fallback`. Scenarios must map supported event types and declared class names. People/vehicle can provide tracker YAML with ByteTrack thresholds and buffer.

Metadata validation checks schema, paths, configs, scenario compatibility, weight presence, and optional SHA-256. A missing checkpoint reports `MISSING_WEIGHTS`; it never becomes a dummy detector. Runtime validation imports Ultralytics, loads the trusted local checkpoint, confirms detection task and class map, checks requested device availability, and warms up on an internal blank image. Only successful runtime validation reports `READY`. A checksum establishes integrity, not trust. `.pt` files must be approved by the responsible teammate.

Both example packages intentionally have no checkpoint, provenance, or evaluation metrics. `evaluation.json` says `NOT_PROVIDED`; model-card placeholders must be completed by package owners. The supplied people/vehicle class map is an example contract and must be changed to exactly match the submitted checkpoint before runtime load.
