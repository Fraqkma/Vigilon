## Shared Live Monitoring (2026-10-24)

Implemented on `feat/live-monitoring`, based on committed Map feature `4d7cea5` (stacked on `feat/map`; not merged into `main`). The browser only refreshes freshness/rate on a new frame identity; displayed new-frame rate is explicitly distinct from source target/inference FPS. No schema migration or upstream camera connection behavior was added. Implementation and QA detail: [Live Monitoring feature](LIVE_MONITORING_FEATURE.md).
